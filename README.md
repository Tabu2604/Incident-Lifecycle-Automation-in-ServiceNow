# Incident-Lifecycle-Automation-in-ServiceNow
Developed an automated Incident Management solution in ServiceNow that streamlines the incident lifecycle from creation to resolution using workflow automation. Integrated Knowledge Management and Change Management to enable faster issue resolution, reduce recurring incidents, and improve IT service efficiency.

### Phase 1: Requirement Analysis & Planning
Analyzed the project requirements and planned the ServiceNow configuration and incident management workflow.

### Phase 2: Create New Service, Service Offering
Created a new service and configured its service offering to support the required IT service management process.

### Phase 3: Incident Record Creation
Created incident records with the required information to initiate the incident management lifecycle.

### Phase 4: Incident Classification
Classified incidents using appropriate categories, subcategories, priorities, and other relevant fields.

### Phase 5: Knowledge Integration
Used Knowledge Management to identify relevant knowledge articles that can support incident resolution.

### Phase 6: Reassignment & Escalation
Reassigned incidents to appropriate users or groups and performed escalation when required.

### Phase 7: Incident Tracking by Level 2
Tracked and managed incidents at Level 2 support for further investigation and resolution.

### Phase 8: Emergency Change Request Creation
Created an Emergency Change Request when an incident required an urgent system change.

### Phase 9: Child Incident Creation
Created child incidents to manage related issues separately while maintaining their relationship with the parent incident.

### Phase 10: Incident Resolution
Resolved the incident by performing the required actions and recording the appropriate resolution information.

### Phase 11: Knowledge Creation
Created a new knowledge article based on the incident resolution to support future issue resolution.

### Phase 12: Final Validation
Performed final validation of the incident, related records, configurations, and workflow activities.

### Phase 13: Testing & Deployment Validation
Tested the configured process and validated that the implemented ServiceNow solution works as expected.

### Phase 14: Conclusion
Completed the Incident Management lifecycle and validated the overall ServiceNow solution.
